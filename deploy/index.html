Gerenciamento de Usuários e Permissões

Na tabela abaixo, configure para cada membro a conta, a senha, o departamento/região e as permissões de departamento / região (multi-seleção, que definem o escopo dos dados visíveis na Visão do Gerente). O sistema gera automaticamente a permissão de acesso com base nas permissões de departamento / região selecionadas; novos usuários devem alterar a senha no primeiro acesso.

As alterações são salvas automaticamente; clique em 'Salvar' para persistir toda a configuração; a senha é gravada somente ao clicar em 'Definir / Alterar' (armazenada com hash e salt, nunca em texto puro).
